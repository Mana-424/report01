# 将棋ゲーム

## 1. 作品について

この作品は、Pythonを使用して作成した**2人対戦型の将棋ゲーム**です。

9×9の将棋盤をPythonの二次元リストで表現し、盤上の駒を数字で管理しています。

駒にはそれぞれ番号を割り当てており、例えば、

- `1`：歩
- `2`：香車
- `3`：桂馬
- `4`：銀
- `5`：金
- `6`：角
- `7`：飛車
- `8`：玉

として管理しています。

また、**正の値を下側の駒、負の値を上側の駒**として表すことで、同じ数字でもどちらのプレイヤーの駒なのかを判別できるようにしています。

この作品では、単純に駒を動かすだけではなく、以下の機能を実装しています。

- 駒の移動
- 駒取り
- 持ち駒
- 持ち駒を盤上に打つ
- 駒の成り
- 二歩の禁止
- 行き所のない駒の禁止
- 王手の判定
- 自分の王が王手になる手の禁止
- 詰みの判定

など、実際の将棋に近いルールを実装しています。

---

## 2. 遊び方

このゲームは、**1台のコンピュータを使って2人で交互に対戦**します。

ゲームを開始すると、将棋盤とそれぞれの持ち駒が表示されます。

最初は**下側が先手**となり、下側と上側が交互に駒を動かします。

---

## 3. 盤面の見方

盤面は9×9のマスで構成されています。

横と縦の座標は、それぞれ `1～9` の数字で表されています。

例えば、以下のように表示されます。

![将棋ゲームの盤面](images/HANN(1).png)

このゲームでは、駒を動かすときに、

**「移動元の横 → 移動元の縦 → 移動先の横 → 移動先の縦」**

の順番で4桁の数字を入力します。

例えば、

```text
7776
```

と入力すると、

7筋7段から7筋6段へ駒を移動するという意味になります。

---

## 4. 駒を動かす

自分の手番になると、最初に

```text
持ち駒を使いますか？ y/n :
```

と表示されます。

盤上の駒を動かす場合は、

```text
n
```

を入力します。

その後、

```text
指し手を入力してください（例：7776）
```

と表示されます。

ここで移動元と移動先を4桁で入力します。

例えば、

```text
7776
```

と入力すると、7筋7段の駒を7筋6段へ移動させます。

プログラムでは入力された手について、以下の条件を確認します。

- 移動元に駒があるか
- 自分の駒であるか
- 移動先に味方の駒がないか
- その駒が指定された場所へ移動できるか
- 移動後に自分の王が王手されないか

条件を満たしていれば、駒が移動します。

---

## 5. 駒を取る

移動先に相手の駒がある場合、その駒を取ることができます。

取った駒は盤上からなくなり、自分の持ち駒になります。

例えば、相手の歩を取った場合、

```text
持ち駒 : [1]
```

のように表示されます。

また、成り駒を取った場合は、元の駒に戻して持ち駒に追加します。

| 取った駒 | 持ち駒になる駒 |
|---|---|
| と | 歩 |
| 杏 | 香車 |
| 圭 | 桂馬 |
| 全 | 銀 |
| 馬 | 角 |
| 龍 | 飛車 |

これは実際の将棋のルールに合わせたものです。

---

## 6. 持ち駒を使う

持ち駒がある場合は、盤上に駒を打つことができます。

最初に、

```text
持ち駒を使いますか？ y/n :
```

と聞かれるので、

```text
y
```

を入力します。

すると、自分が持っている駒が表示されます。

例えば、

```text
持ち駒 : [1, 4]
```

と表示された場合、歩と銀を持っていることになります。

その後、

```text
使いたい駒を選択してください
```

と表示されるので、使いたい駒の番号を入力します。

例えば、

```text
1
```

と入力すると、歩を打つことができます。

次に、

```text
駒の置く場所を選択してください
```

と表示されるので、置きたい場所を2桁で入力します。

例えば、

```text
43
```

と入力すると、4筋3段に駒を打ちます。

---

## 7. 持ち駒を打つときのルール

持ち駒はどこにでも打てるわけではありません。

このプログラムでは、以下のルールを実装しています。

### 二歩

同じ筋に自分の歩が存在する場合、その筋に歩を打つことはできません。

### 行き所のない歩

一番奥の段に歩を打つことはできません。

### 行き所のない香車

一番奥の段に香車を打つことはできません。

### 行き所のない桂馬

桂馬は一番奥の2段に打つことができません。

### 駒がある場所

すでに駒が置かれている場所には、持ち駒を打つことができません。

さらに、持ち駒を打った結果、自分の王が王手される場合も、その手は認められません。

---

## 8. 駒の成り

歩、香車、桂馬、銀、角、飛車は、相手陣に入ることで成ることができます。

駒を移動した後、成ることができる場合、

```text
成りますか？ y/n :
```

と表示されます。

成る場合は、

```text
y
```

成らない場合は、

```text
n
```

を入力します。

例えば、歩が成ると「と」になります。

| 元の駒 | 成った駒 |
|---|---|
| 歩 | と |
| 香車 | 杏 |
| 桂馬 | 圭 |
| 銀 | 全 |
| 角 | 馬 |
| 飛車 | 龍 |

ただし、歩・香車・桂馬については、成らないと次に移動できなくなる場所に移動した場合、自動的に成ります。

例えば、歩を一番奥の段まで進めた場合、歩のままでは次に動けないため、自動的に「と」になります。

---

## 9. 王手の判定

このプログラムでは、王手の判定も行います。

`check_from_king()` という関数を使って、自分の王が相手の駒から攻撃されているかを確認します。

確認する駒は、

- 飛車
- 龍
- 香車
- 角
- 馬
- 桂馬
- 歩
- 金
- 成り駒
- 銀
- 王

です。

例えば、相手の飛車が同じ縦方向や横方向にあり、その間に駒が存在しない場合、自分の王が王手されていると判定します。

---

## 10. 自分の王が王手される手の禁止

将棋では、自分の王が王手される状態になる手を指すことはできません。

このプログラムでは、

`safe_after_move()`

という関数を使って、このルールを実現しています。

この関数では、実際に駒を動かす前に、仮にその駒を動かした状態を作ります。

そして、その状態で自分の王が王手されているか確認します。

王が安全ならその手を許可し、王手される場合はその手を禁止します。

この仕組みによって、

「自分の王を守らずに駒を動かしてしまう」

といった不正な手を防ぐことができます。

---

## 11. 王手と詰みの判定

相手の王に王手をかけると、

```text
王手！
```

と表示されます。

その後、

`has_legal_move()`

という関数を使って、王手された側に王手を防ぐ方法が残っているかを調べます。

この関数では、相手の全ての駒について、

- どこへ移動できるか
- その移動が合法か
- 移動した後に王が安全か

を確認します。

王手を防ぐ方法が1つでもあればゲームは続きます。

反対に、

**王手されていて、王手を防ぐ合法的な手が1つもない場合**

は詰みとなり、ゲームが終了します。

---

## 12. プログラムの主な関数

このプログラムでは、処理を分かりやすくするために複数の関数を作っています。

| 関数名 | 役割 |
|---|---|
| `board_show()` | 将棋盤と持ち駒を表示します。 |
| `movement()` | 駒を実際に移動させます。 |
| `find_king()` | 指定した側の王が盤面のどこにあるのかを探します。 |
| `check_from_king()` | 王が相手の駒から王手されているかを確認します。 |
| `move_of_piece()` | 指定した駒が指定した場所へ移動できるかを確認します。 |
| `get_piece()` | 相手の駒を取って、自分の持ち駒に追加します。 |
| `can_drop()` | 持ち駒を指定した場所に打てるか確認します。 |
| `use_piece()` | 持ち駒を実際に盤上へ打つ処理を行います。 |
| `safe_after_move()` | 駒を仮に動かし、移動後に自分の王が安全か確認します。 |
| `in_promotion_zone()` | 駒が成ることのできる範囲に入っているか確認します。 |
| `must_promote()` | 歩、香車、桂馬などが、必ず成らなければならない場所に移動したか確認します。 |
| `evolution()` | 指定された駒を成り駒へ変更します。 |
| `promotion_check()` | 駒を移動した後、成るかどうかをプレイヤーに確認します。 |
| `has_legal_move()` | 王手された側に、王手を解除できる合法的な手が残っているか確認します。 |
| `check_status()` | 現在、指定した側の王が王手されているか確認します。 |

### 各関数の詳細

#### board_show()

`piece` という辞書を使って、盤面に保存されている数字を「歩」「香」「桂」などの文字に変換して表示します。

#### movement()

移動先に駒を移し、移動元を空にします。

#### find_king()

指定した側の王が盤面のどこにあるのかを探します。

#### check_from_king()

王が相手の駒から王手されているかを確認します。このプログラムの王手判定の中心となる関数です。

#### move_of_piece()

駒ごとに移動ルールが異なるため、歩、香車、桂馬、銀、金、角、飛車、王、成り駒、馬、龍に分けて処理しています。

#### get_piece()

相手の駒を取って、自分の持ち駒に追加します。成り駒を取った場合に、元の駒へ戻す処理も行います。

#### can_drop()

二歩や行き所のない駒などのルールを確認し、持ち駒を指定した場所に打てるか確認します。

#### use_piece()

持ち駒を実際に盤上へ打つ処理を行います。

#### safe_after_move()

駒を仮に動かし、移動後に自分の王が安全か確認します。

#### in_promotion_zone()

駒が成ることのできる範囲に入っているか確認します。

#### must_promote()

歩、香車、桂馬などが、必ず成らなければならない場所に移動したか確認します。

#### evolution()

指定された駒を成り駒へ変更します。例えば、歩を「と」に、角を「馬」に変更します。

#### promotion_check()

駒を移動した後、成るかどうかをプレイヤーに確認します。

#### has_legal_move()

王手された側に、王手を解除できる合法的な手が残っているか確認します。詰みの判定に使用しています。

#### check_status()

現在、指定した側の王が王手されているか確認します。

## 13. ゲーム全体の流れ

このプログラムのゲーム全体の流れは次のようになっています。

```text
ゲーム開始
    ↓
盤面を表示
    ↓
現在の手番を表示
    ↓
持ち駒を使うか選択
    ↓
┌──────────────┐
│              │
y              n
│              │
↓              ↓
持ち駒を選択    移動元・移動先を入力
│              │
↓              ↓
打てるか確認    駒の動きを確認
│              │
↓              ↓
王が安全か確認  王が安全か確認
│              │
↓              ↓
駒を盤上へ      駒を移動
               ↓
             駒を取る
               ↓
             成りを確認
               ↓
         相手が王手されているか確認
               ↓
       相手に合法的な手があるか確認
               ↓
           手番を交代
               ↓
          ゲームを継続
```

相手が王手されていて、王手を解除する合法的な手が1つもない場合、ゲーム終了となります。

## 14. 工夫した点

この作品では、プログラムが複雑になりすぎないように、処理ごとに関数を分けました。

例えば、

- 駒を動かす → `movement()`
- 駒の動きを確認する → `move_of_piece()`
- 駒を取る → `get_piece()`
- 持ち駒を打つ → `use_piece()`
- 王手を確認する → `check_from_king()`
- 王が安全か確認する → `safe_after_move()`
- 詰みを確認する → `has_legal_move()`

というように、それぞれの役割を分けています。

また、駒を数字で管理し、正負によってプレイヤーを区別したことも工夫した点です。

例えば、

```python
1
```

なら下側の歩、

```python
-1
```

なら上側の歩を表します。

この方法を使うことで、駒の種類と所属する側を一つの数字で管理することができます。

## 15. 作品を制作して学んだこと

この作品を制作することで、Pythonの基本的な文法だけではなく、複数の処理を組み合わせて一つのゲームを作る方法を学びました。

特に、将棋では駒によって移動方法が違うため、多くの条件分岐が必要になります。

さらに、

- 途中に駒があるか
- 相手の駒か味方の駒か
- 移動後に王手になるか
- 成ることができるか
- 持ち駒を打つことができるか
- 王手を解除できる手が残っているか

など、多くの条件を考える必要があります。

そのため、この作品を通して、条件分岐、繰り返し処理、リスト、辞書、関数、変数などを組み合わせて、複雑なルールをプログラムで表現する方法を学ぶことができました。
